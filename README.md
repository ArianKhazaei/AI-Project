# 🎙️ Ava (آوا)

> **یک دستیار هوشمند مبتنی بر تبدیل پرامپت، پردازش زبانی و خروجی صوتی برای ویندوز**

**Ava** سیستمی است که پرامپت‌های خام کاربر را دریافت، تحلیل و مهندسی می‌کند؛ سپس پرامپت بهینه‌سازی‌شده را به مدل زبانی (LLM) ارسال کرده و پاسخ نهایی را به گفتار (Text-to-Speech) تبدیل و در بلندگوهای سیستم پخش می‌کند.

---

## 🧭 معماری و خط لوله (Pipeline)

جریان داده در Ava به‌صورت گام‌به‌گام و ماژولار پیاده‌سازی شده است:
```text
User Prompt (ورودی خام کاربر)
│
▼
Prompt Generator (مهندسی و بهینه‌سازی پرامپت)
│
▼
Final Prompt (پرامپت ساختاریافته)
│
▼
LLM Engine (ارتباط با OpenAI API)
│
▼
Text Response (پاسخ متنی هوش مصنوعی)
│
▼
TTS Engine (تبدیل متن به صوت با قابلیت تغییر درایور)
│
▼
Windows Audio Output (پخش مستقیم صوت روی ویندوز)
